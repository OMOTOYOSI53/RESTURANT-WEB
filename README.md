# BLESSINGS — Premium African & Nigerian Restaurant Website

A professional, modern, responsive, and functional four-page website for **BLESSINGS**, an authentic African and Nigerian luxury restaurant.

> *"Bringing the authentic taste of Africa to your table."*

---

## 🌟 Features

- **Four Complete Pages**:
  - **Home**: Full-width atmospheric hero, welcome introduction, 6 signature dish highlights with direct order buttons, "Why Choose Us" features, restaurant experience section, guest testimonials, and call-to-action banner.
  - **About Us**: Brand story, mission, vision, 4 core values (Quality, Authenticity, Hospitality, Customer Satisfaction), and an interactive image gallery with category filtering and lightbox modal view.
  - **Our Services & Menu**: 20+ dishes across 5 categories (*Rice Dishes, Soups & Swallows, Grills & Proteins, Local Specialties, Drinks & Beverages*), real-time search, 6 hospitality service cards, interactive order cart, table reservation form, and direct WhatsApp integrations.
  - **Contact Us**: Clickable phone (`tel:`) and email (`mailto:`) links, direct WhatsApp chat link, validated contact form, provisional location placeholder, editable sample opening hours, and social media links.
- **WhatsApp Integration**:
  - Direct WhatsApp food order generation to `+2348144638639` with itemized dishes, portions, customer delivery details, and calculated totals in Nigerian Naira (₦).
  - Table reservation enquiry generation with guest count, seating preference, and date/time.
  - Contact enquiry message formatting.
- **Design System**:
  - Palette inspired by warm rustic wooden restaurant interiors:
    - **Deep Espresso**: `#21150F`
    - **Dark Walnut**: `#493023`
    - **Wood Brown**: `#80502D`
    - **Antique Gold**: `#C18A45`
    - **Amber Gold**: `#E2B66F`
    - **Warm Cream**: `#F3E8D5`
- **Fully Responsive**:
  - Seamless layout across desktop, tablets, and mobile devices with interactive hamburger navigation.

## 🚀 Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/OMOTOYOSI53/RESTURANT-WEB.git
   cd RESTURANT-WEB
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
